# AMG GT 第一人称漫游录制

路线约两分钟：入口环视 → 车头与左前轮 → 开门、俯身并连续坐入左侧驾驶位 → 前方视野、仪表、方向盘、中控与副驾评审 → 下车关门 → 绕车尾和右侧 → 车前爆炸展示与组装还原。步速约 0.78 米/秒，站立眼高 1.65 米，视场角 60°，镜头连续行走和转头。

在仓库根目录构建独立正式播放器：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\CarAR\Tools\Build-Windows.ps1 -Presentation
```

双击 `启动发布会演示.cmd`，或运行 `CarAR/Launch/Start-Presentation.ps1 -Autoplay`；自动播放会留出 15 秒准备时间。F6 开始或重播，F7 暂停路线，Esc 恢复手动漫游。路线结束后保持整车画面。

导出需要支持 libx264 的 FFmpeg，可通过 `CARAR_FFMPEG` 环境变量、PATH 或启动参数指定。例如使用本机 EV 自带编码器：

```powershell
.\录制4K发布会视频.cmd -FfmpegPath 'D:\Soft\EVCapture\ffmpeg.exe'
```

成片写入 `CarAR/Build/Presentation/Recordings/AMG-GT-review-4K60-时间戳.mp4`，每次独立命名，H.264、CRF 12、3840×2160、60fps，无音轨。输出直接来自相机，不受桌面遮挡或显示器分辨率影响。配套 `.frames.json` 保存帧数与时长，`.encoder.log` 保存编码诊断。

录制使用 4K HDR 相机目标、2 倍内部渲染边长和 8x MSAA，再输出 sRGB 视频；关闭动态分辨率和时间抗锯齿。保留源场景 Hamburg HDR 的映射、Cycles 烘焙与室内反射，使用源 Filmic / Medium High Contrast LUT。发布会模式另采用参考图确认的车漆亮度和房间色彩系数，普通 MR / VR 使用各自的光照设置。

导出时每帧按 1/60 秒推进，窗口可能慢放，视频保持正常速度。请等日志出现 `[CarAR Walkthrough Video] SAVED` 后再关闭程序。EV 可同时录制窗口作为现场预览备份；发布会播放使用程序导出的文件。

完整自动检查可运行 `Start-Presentation.ps1 -Check -Export -FfmpegPath <ffmpeg.exe>`，两秒后开始，路线完成后退出。`Build/Presentation/walkthrough-take.json` 记录世界固定、整车还原、连续视角和驾驶位到达结果；检查模式还生成各阶段截图。按 Esc 中止导出时会保留已录片段，完整路线成功与否以 COMPLETE 日志及 take 结果为准。
