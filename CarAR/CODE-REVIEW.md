# 项目最终审查 · 2026-10-26

审查范围为自有运行代码、编辑器构建、启动与导出脚本、着色器和资源依赖；第三方包保留运行依赖、兼容补丁与许可证。唯一 Unity 工程为 `CarAR`。

## 修复与精简

- 统一开发版和发布会版构建，恢复构建前的图形 API 配置；已导出的模型足够构建，原始 Blender 文件可选。
- 删除旧镜头剪切演示、重复构建实现、无效 TAA / 运动矢量设置和外部实验光照配置，保留连续第一人称路线及真实驾驶位评审。
- 删除未保存有效组件的 Bloom 配置、禁用的 VR SSAO 副本与重复反射烘焙，保留源 Cycles 光照与 LUT。
- 录制统一为原生 4K60。每次导出独立命名；编码失败、路线失败和中止都会释放目标、进程并恢复时间与相机状态。
- 修复普通桌面 VR 的“录屏优化”被发布会超采样覆盖；发布会画质仅在显式漫游模式启用。
- VR 材质变体复用稳定 GUID / 子资源 ID，并在缓存构建时从当前 MR 源材质刷新，避免重复构建丢引用或保留过期材质。
- 修复复用 VR 菜单时字体共享材质覆盖未保存的问题；显式记录 Prefab 属性，并使用 BuildFailedException 阻止存在缺失引用的构建。
- 构建前检查三个场景的缺失脚本、对象引用、材质和着色器错误；依赖审计结果仅用于人工判断，保留动态加载、编辑器输入和 ProjectSettings 引用的资产。
- 删除历史根工程、旧 911、废弃 SDK 示例、一次性探测工具、实验 HDR 和重复烘焙资源。临时贴图改写到 tmp，导出后移除已打包替代的粗糙度输入。
- 清除本机旧日志、缓存、试录和过期发行包，保留最终 4K60 成片、参考截图、正式播放器与当前 Unity 导入缓存。常规 Git 提交不包含视频、构建和临时数据。

本机清理阶段删除 8,892 个文件，释放约 11.61 GiB；Git 历史保持完整，没有改写历史。

## 保留的边界

自动回归覆盖软件行为，无法替代头显双眼显示、舒适度、实机帧率及荟镜透视配准的佩戴验收。当前 MR 使用静态 HDR，没有已验证的现实测光提供方或跨会话持久锚点。实时 URP 与 Cycles 在玻璃折射、面光源阴影和间接光精度上仍有差异。录制要求显卡支持相应的 4K HDR / MSAA 目标，并安装支持 libx264 的 FFmpeg。
