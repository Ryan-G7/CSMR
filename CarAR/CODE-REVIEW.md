## 手柄唤醒复现：定位跳变与遗漏门饰条

本节对应最新修订；下文保留各轮审查与验证的历史记录。

这次 `huijing-mr.log` 中车辆 local/world scale 始终为 `(1,1,1)`，没有解锁或缩放命令。t=115.7291 秒，原生 HMD、相机、双眼中心同时从 y=-1.1296 跳到 -15.8070，头显仍报告 Position / Rotation 且 presence=True；已跟踪手柄距头显达 14–16 米。旧版仅凭头显标志认为就绪，随后把车放在 y=-17.306 的估计地面。t=130.4631 秒，手柄重新连接并激活后，头显回到 y=-1.0923；汽车仍在旧坐标，视觉上远离并变小。上轮 `31df079` 的缩放保护没有解决这个主因。

- 首次 PC 摆放同时检查原生头显与至少一只 grip 手柄是否处于合理的共同空间；不一致、未佩戴或定位无效会重置等待。连续稳定 1 秒后才开始地面搜索超时。读取与相机 TrackedPoseDriver 同源的 XRHMD 和实时 grip action，不使用上一帧射线 Transform。
- 停车后仍监测跟踪，异常时锁车并暂时关闭 Renderer / Collider，同源恢复稳定后恢复。保留根对象活动，避免中断爆炸动画协程。已跟踪的有效姿态发生不合理大跳变时要求显式重停，并用当前眼高估计预览地面，避免继承旧地面。没有给相机或输入增加坐标补偿。
- 删除重复缩放日志、相关缓存及命令来源参数，保留已通过独立复现验证的握键 / 摇杆防误触与双手距离退化保护。没有把这些真实的独立问题说成此次实机现象的主因。
- 按开门截图的像素射线反查源网格，上杆为 `Cube.013`（左右各一独立岛），下杆来自 `Cube.092`。后者还包含中控台，导出只分配两侧各 109 顶点的长条给门；另两块中心网格留在 Body。增加分岛数量、范围和顶点数校验，避免整块混合内饰随门运动。Blender 材质与原始文件不改动。

## 结构与质量判断

车辆、摆放、输入、UI、光照和原生接口已有独立组件，继续使用 Unity / MRTK / XRI 负责姿态、交互和约束的方向合理。本次优先修复跨组件状态约束，没有另建一套交互或跟踪框架。

后续质量工作的重点是明确应用状态与评审数据模型。当前 UI 仍依赖按钮数字索引，CarShowroom 还包含较多诊断和冒烟测试代码，HJXR 反馈依赖厂商日志格式；这些均是维护成本。若菜单继续扩展，应引入具名动作绑定；测试宜逐步进入独立测试程序集，原生完成反馈优先改用厂家正式支持的接口。当前 SDK 中未实现的 getter 不能作为替代方案。

模型约 131 万三角形，存在大量分件和 MeshCollider；4096 阴影、SSAO、反射探针及双眼渲染的实际成本需要在目标头显上剖析。没有充分依据直接删除几何、替换精确碰撞或声称满足所有场景的帧率要求。

## 完整汽车 MR 评审仍缺少的能力

1. **可重复的空间验收。** 记录实体定位板重合误差、车辆与地面的误差、不同距离/视角下的偏差，测试走动、遮挡、跟踪丢失与恢复。当前设备链路没有已建立的跨会话持久锚点方案；不能声称重启后能恢复同一大厅位置。
2. **评审任务与记录。** 缺少项目/车型/版本、评审人员、检查项、问题等级、结论、批注/截图和导出报告的数据结构与持久化。当前 UI 中的 ConfirmedCount 是按钮诊断计数，不是评审记录。
3. **工程测量。** 缺少带单位和精度说明的尺寸、间隙、面差等测量工具，以及测量结果与模型版本的关联。模型 1:1 当前指源模型单位，尚无原厂尺寸标定；爆炸图是展示动画，不能作为装配过程或机构干涉计算。

5. **可迁移构建与性能基线。** MRTK 为仓库内本地包，迁移时必须保留依赖目录。正式交付前建立固定设备、运行时和 SDK 版本、性能采样与发布构建流程，记录兼容补丁的上游版本。

## 2026-10-20 尺寸突变与现实测光核查

用户报告转头或拿起手柄后车辆闪现、缩小。源模型首次加载的包围盒为 2.082 × 1.349 × 4.676 米，初始比例为 1。旧日志没有比例记录，无法把用户那次现象唯一归因于某次输入。

新增真实 MRTK 选择测试复现了缩小路径：两个抓取点位置重合时，原 ScaleLogic 按当前/起始手柄距离计算比例，0.15 秒内车辆降至约 0.77 倍，测试失败并以 1 退出（`scale-repro-smoke.log`）。应用现使用 VehicleScaleLogic：单手不读取射线附着点缩放；距离不足 8cm 或非有限时冻结比例，恢复后重新建立基准。XRI 握键射线在解锁、恢复跟踪和输入重新启用后都要求先释放握键，避免 State 模式立刻重新选中车辆。保留正常双手缩放与摇杆精调。

增加首次隐藏/激活、转头保持位置/比例/活动状态、单手附着点变化、双手位置重合/恢复、按住握键并推着摇杆时解锁、输入启停和跟踪恢复的回归；摇杆先回中才允许新的整车变换，重新启用输入时在激活父物体前禁用抓取射线。实际缩放与停车日志补充 local/world scale。目标头显上报告的整体现象仍需佩戴复核，不能把模拟测试通过视为最终合成验收。

当前实机日志没有 XRCameraSubsystem 或 XREnvironmentProbeSubsystem，已核查的厂家相机接口也未提供测光输入。当前只有静态 HDR 环境光与反射，默认无补光。界面、自动模式反馈和来源诊断明确区分无提供方、等待数据、有效测光与手动补光；模拟测光测试不代表此设备具有该能力。

最终验证：`scale-final-build.log` 对应 Windows 构建退出码 **0**；`scale-final-smoke.log` 中 MRTK、真实 Input System 控制器、状态回归和整车动画四组全部 PASS，播放器退出码 **0**，完整播放器日志无异常。保留源模型、材质和 HDR；场景仅更新缩放逻辑类型，去除自动重建带来的对象 ID 与资源空白差异。构建日志中此前已有的编辑器程序集分析 EndOfStream 和 JobTempAlloc 警告仍存在。
